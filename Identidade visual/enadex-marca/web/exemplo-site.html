Entenda o que pesa em cada nota do ENADE.

O EnadeX cruza os microdados do ENADE com modelos de aprendizado de máquina e mostra, variável por variável, o que está associado ao desempenho de cada curso.

Como funciona

  1. Dados

    Os microdados públicos do ENADE, com o desempenho e o questionário socioeconômico de cada participante.

  2. Modelo

    Um modelo aprende a prever a nota a partir dessas variáveis, curso a curso.

  3. Explicação

    Cada previsão é decomposta: quanto cada variável empurrou a nota para cima ou para baixo.
